# Security Policy

## Reporting a Vulnerability

We take the security of RemitSave Africa seriously. If you discover a security vulnerability, please do **not** open a public issue.

Instead, send a private report to **ogazipromise@gmail.com**.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (if known)

You can expect an acknowledgement within 48 hours and a detailed response within 5 business days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | ✅        |

## Responsible Disclosure

We kindly ask that you:
- Give us reasonable time to fix the issue before disclosing it publicly
- Make every effort to avoid violating privacy, destroying data, or interrupting our services
- Do not exploit the vulnerability beyond what is necessary to demonstrate it

## Bug Bounty

We do not currently offer a bug bounty program, but we deeply appreciate and will publicly acknowledge responsible disclosures.
